Publish:
1. Extract this ZIP.
2. Upload all files directly into the root of your GitHub repository (not a nested folder).
3. Open Settings > Pages.
4. Choose Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for deployment, open the HTTPS URL, and test camera scanning, image upload, links, and all pages.

Important:
- This package is prepared with AdSense-readiness in mind, but it does not guarantee approval.
- Review Google's current policies before applying and whenever policies change.
- If you add AdSense or analytics, update the privacy disclosures and implement any required consent mechanism for your visitors' regions.
- Place any future ads clearly apart from scan, upload, copy, and link-opening controls.
- Test the live site before applying.
- The scanner uses the html5-qrcode library from a CDN and needs internet access.
